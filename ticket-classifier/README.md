# Student Workspace

Build the Ticket Classifier here as you follow the 60-day path.

On Day 1, run this command from the repository root:

```bash
mkdir -p ticket-classifier/{notes,scripts,data,logs}
```

Do not generate the final project structure immediately. Add files only when the curriculum introduces them. The expected final shape and behavior are described in the [capstone brief](../projects/capstone.md).

Start with the [student guide](../STUDENT_GUIDE.md), then use the [progress tracker](../CURRICULUM.md).
