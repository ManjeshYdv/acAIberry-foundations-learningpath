# System Tools

## htop

- Package: `htop`
- Command: `htop`
- Path: `/usr/bin/htop`
- Version: `3.3.0-4build1`
- Purpose: Interactive process and resource monitoring.
- Real-world use: Check CPU, memory, and running processes when debugging a server.

## curl

- Package: `curl`
- Command: `curl`
- Path: `/usr/bin/curl`
- Version: `8.5.0-2ubuntu10.13`
- Purpose: Make HTTP and other network requests from the command line.
- Real-world use: Test APIs, backend endpoints, HTTP responses, and connectivity.

## ripgrep

- Package: `ripgrep`
- Command: `rg`
- Path: `/usr/bin/rg`
- Version: `14.1.0-1`
- Purpose: Fast recursive text search.
- Real-world use: Search source code, configuration files, logs, and large projects.

## Package Management Commands

| Command | Purpose |
|---|---|
| `apt search <package>` | Search available packages |
| `apt show <package>` | Inspect package metadata |
| `sudo apt update` | Refresh package repository metadata |
| `sudo apt install <package>` | Install a package |
| `dpkg -l` | List installed Debian packages |
