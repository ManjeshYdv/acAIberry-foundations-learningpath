#definition 

PID = a unique number assigned to a running process. For my sleep 300 process, the PID was 1891130.

Foreground = a process that is directly connected to and controlled by the current terminal.

Background = a process that continues running while the terminal is available for other commands. **sleep 300 &**

CPU = the amount of processor resources being used by a process.

Memory = the amount of RAM being used by a process.

SIGTERM = the normal termination signal sent by kill, which asks a process to terminate gracefully.
