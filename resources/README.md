## What comes next

After this path, pick one direction based on your goal:

- deeper ML: feature engineering, cross-validation, experiment tracking, and model monitoring;
- generative AI: model APIs, embeddings, RAG, evaluations, and safety;
- platform work: Terraform, managed container services, Kubernetes, and observability;
- application engineering: databases, authentication, frontend development, and API design.

Do one next project rather than adding every topic to this one.
